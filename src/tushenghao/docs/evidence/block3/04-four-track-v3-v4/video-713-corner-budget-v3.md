# 713实拍组四角误差与预算重定

用户明确批准本轮实拍重定：nearest-rank P99+1原图px；合成C原统计方法和1.5px历史预算保留。
固定原视频v2的713完整补全帧、2852个角；扩大弧前后用同一旧生产者矩阵和六片assignment，不从视频构造真值父、不丢首失败后的角。
仅解除待求max_corner_error上限；其他拟合、关联、延伸、连接及病态预算仍冻结。误差为交点到实际转折弧距离，不是人工真值定位误差。
