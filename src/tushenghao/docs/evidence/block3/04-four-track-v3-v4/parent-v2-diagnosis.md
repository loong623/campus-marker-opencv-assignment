## 分类与首凹点的具体反例

- **帧 34（首凹点选错的证据）**：六组件，四个 L 候选；component 0 为 7 顶点、凹点索引 `[2,3]`，正式只取第一个索引 2。正式所有父被拒，最佳最坏残差 5.509606 >5。诊断仅枚举同一个观测已存在的凹点，使用索引 3 后可得到正 determinant=2.490234 父，三个 L 残差分别 1.593444、1.567816、1.868695，面积比 1.050647、1.009686、0.988962。没有改变模型、类别剪枝或残差上限。它证明存在合法实测锚点被“第一个凹点”单选排除，尚非人工真值身份确认。
- **帧 4（候选类别排除与错误对应的证据）**：六组件，只有三个支持 L。component 0 简化为 8 顶点、2 个凹点，类别为 M，未进入三 L 组合；component 3 为 6 顶点、1 凹点，类别为 L。所有 6 个排列失败；最佳父把 component 3 对应 L2，该片残差 17.076112，面积比 2.657710，多个投影顶点距轮廓 24–26 px。枚举已有凹点不能恢复。诊断只把 epsilon 改为 3 或 4 工作 px，出现四个 L 候选与两个验证父。因此固定顶点数分类对分段变化敏感；不宜以增大 residual 接纳这个明显形状不合的父。
- **帧 37（组合前已丢候选）**：六组件的顶点数为 `[8,6,3,5,4,7]`，仅两个 L；component 0 的 8 顶点被类 M 排除，组合数为 0。只读 epsilon=2.5 产生三个 L 与两个验证父；epsilon=3、4 又没有父。一个更大 epsilon 不能普遍代替正确的候选拓扑机制。

323 个残差全拒帧中，**98 帧**通过工具枚举同一观测已有凹点得到至少一个正 determinant 的验证父；其余不因此恢复。仅诊断枚举 epsilon `{1,1.5,2.5,3,4}` 可在 323 中恢复 321 帧，在 257 少 L 帧中恢复 21 帧。这里“恢复”仅指该冻结旧 validator 保留父，不代表 M/S 成功、角点成功或真值正确；枚举各项存在重叠，不能相加为检测收益。所有隔离输出标记 `diagnostic_only`，未用于重定生产参数。

## 暂停点与可审方案

按用户“若为模型结构问题则暂停并报方案”执行：这里不是图纸坐标错误，而是冻结三 L 上游 **固定 6/7 顶点类剪枝 + 第一个凹点单锚点** 无法覆盖实拍/圆角分段。将以下作为独立设计方案报主 agent，不擅实现：

1. 保留模型三 L、模型坐标、仿射方向及最终残差/面积检验。观察侧用实际连续轮廓及明确 L 拓扑提供有界多候选，避免仅按简化顶点数排除真实 L；S/M 不因少一个简化顶点直接冒充 L。
2. 三 L 搜索对每个候选枚举实际已有凹点锚点，保持身份、正仿射和资源截断语义。资源上限必须包括该新分支；不能默认为搜索无限完整。
3. 工作白阈值 200 不覆盖灰度最高 150 的帧。如果这些帧确有 MARK，需另行审定亮度/曝光适用范围或分割方案，不能从无真值视频臆测新的阈值。先以原图灰度/人工标签区分暗帧、场景缺失、运动模糊与完整可见目标。
4. 设计一旦获准，应逐项固定新候选规则，跑全 H 并逐 ID 保留旧 689 的通过集合，再跑全视频，记录候选、锚点、残差和资源截断；视频未标注仍不报召回/误检率。
