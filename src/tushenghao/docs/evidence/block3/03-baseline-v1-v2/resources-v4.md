# M/S资源压力测量（批准策略128/4096/64）

每父每缺失片扫描128候选、整个batch最多4096扩展、最多64输出。达到上限且确有下一合法分支待处理时停止，不将父截断误当此次耗尽；精确K与剩余工作分别有回归。
输入是固定真实轮廓的合法候选复制及1/1000父假设，不声称现实图像可以分割出重叠的独立组件。目的是固定压力下检查搜索边界与方向安全性。

所有截断场景orientation_unique=false；所有场景输出≤64，实际扩展≤4096。
优化前1000父×54组件重复扫描约4475ms；现在仅在真实未展开分支触发上限后结束batch，约2.650ms。补全不再在耗尽后继续扫描无可交付收益的父假设；面积不符也先快拒绝，C原始测量不快拒绝。
64分支decode仍约200ms，按角重复整原图取轮廓及逐分支校验占用较大。预算保证有界及截断安全，不等于硬实时保证；本轮没有用户给定的帧时限验收门槛。
