## 4. 冻结实现计划

### 4.1 四点物理定义

图纸固定坐标系以附图展示方向为准，分段角位于模型右上。物理编号随目标固定，不随屏幕旋转改名。

| 编号 | 结构 | 取点 |
|---|---|---|
| P0 | 模型左上完整L | 外侧上边与外侧左边交汇的凸角 |
| P1 | 模型右上分段角 | M块外侧上边与外侧右边交汇的凸角 |
| P2 | 模型右下完整L | 外侧右边与外侧下边交汇的凸角 |
| P3 | 模型左下完整L | 外侧下边与外侧左边交汇的凸角 |

分段角不取S中心、分段质心或包围框角。模型需绑定实际多边形顶点和相邻边编号，沿用板块2模型确认关卡。若M图纸解释与此冲突，提交标注，由用户裁决，不用预测顶替。

当前帧定位步骤：依据结构对应找到相邻外边→原图局部区域提取轮廓边段→普通直线拟合→求交→检查交点在实际转折附近且误差合格。不接亚像素插件。M缺失、必要边不可分、交点病态则该假设无完整检测。

### 4.2 固定屏幕排序规则

输入为[P0,P1,P2,P3]，每项身份由原数组索引确定。排序操作必须携带该索引，输出physical_to_screen，不覆盖或重新解释输入物理身份。

1. 检查凸性后形成图像坐标顺时针环，x向右、y向下。
2. 仅枚举四个循环起点，不任意交换边。
3. 由四点轴对齐范围归一化：u=(x-xmin)/(xmax-xmin)，v=(y-ymin)/(ymax-ymin)。退化范围拒绝。
4. 参考角依次为LT(0,0)、RT(1,0)、RB(1,1)、LB(0,1)。每个循环排列计算E=sum(||p_i-a_i||²)，取最小者。
5. 双精度计算；平局容差为64×double机器精度×max(1,|E1|,|E2|)。平局逐点比较(y,x)，选字典序小者，记录screen_order_tie。

不借历史排序解平局。屏幕LT不是简单最小y点，而是整体最匹配屏幕四角的排列首点。跨菱形分界允许屏幕标签循环换位，物理身份和对应必须正确；不承诺屏幕标签全旋转连续。

### 4.3 方向与歧义

orientation为physical_to_screen[Pj]，值是corners[LT,RT,RB,LB]的索引。marker_code为空，调试假设编号不得显示为有效ID。

| 情况 | 行为 |
|---|---|
| 几何和物理对应一致 | 合并重复解释 |
| 几何在批准误差内一致，方向不同 | 几何有效、orientation空 |
| 几何不兼容 | empty |
| 搜索截断 | 不声明方向唯一，几何仍需独立完整证据 |

几何比较使用无标签四点集合及循环对应，不先按物理标签比较。不平均不同假设的点；几何一致时选观测拟合残差小的实际测量，平局按稳定观测编号选取，不等于该假设语义胜出。

### 4.4 最终有效性

四点都有当前允许证据；必要结构未被边界截断；点有限不重复、凸、不自交；拟合及交点误差合格；原图映射正确；没有无法消除的几何冲突。失败则empty，不裁坐标到画内，不用仿射或历史补点。

### 4.6 类型与关键签名

| 类型 | 内容 |
|---|---|
| CornerBinding | 物理编号、模型片段、顶点及两邻边编号 |
| CornerEvidence | 观测片段、原图边段、直线、交点、误差、截断 |
| CornerMeasurement | 单假设四物理角测量及证据 |
| ScreenOrder | 屏幕点序、physical_to_screen、平局标记 |
| SemanticResolution | 几何一致性、方向唯一性、保留假设、拒绝原因 |
| CornerResolution | resolveObservedCorners的结果包装：成功/失败状态、可选CornerMeasurement及拒绝原因；成功时测量存在，失败时为空，不以零坐标代替失败 |
| ScreenOrderResult | orderScreenCorners的结果包装：成功/失败状态、可选ScreenOrder及拒绝原因；成功时排序结果存在且保留P0～P3身份映射，失败时为空 |
| DetectionValidation | validateDetectionGeometry的校验结果：是否通过及拒绝原因；不包含另一份角点，也不创建Detection；通过时无拒绝原因，失败时给出原因，由调用方停止该测量的有效输出 |

结果明确成功/失败，不用默认零坐标表示失败。

### 4.8 验证集

角证据：完整L外凸角不误取凹点/质心；M外凸角不误取S中心；删M必要边不可补点；预测存在而边不存在则失败；不同缩放后原图无系统偏移。

排序：输入公共数组始终P0～P3；测试可打乱上游观测顺序，但必须先按物理对应重建数组后调用。不得以“输入乱序测试”为由取消物理数组契约。测试环排序内部起点变化、精确菱形、分界循环重排、映射同步更新、物理身份保持。

歧义：同几何异方向→有效几何/方向空；几何冲突→empty；截断不声明唯一；不使用nearest-L、旧ID或历史方向强选。

配置补丁：每个新增定位误差项验证合法加载、缺失/错类型/越界/非有限值拒绝及实际配置导出往返；YAML与detector_config.hpp/cpp字段一致。

视频：固定输入/配置/帧号，分别记录四点有效性、方向唯一性、证据、原始误差与baseline差异。板块0可见性不等于检出率；原32个部分出画失败样本检验拒绝，不恢复画外角。
