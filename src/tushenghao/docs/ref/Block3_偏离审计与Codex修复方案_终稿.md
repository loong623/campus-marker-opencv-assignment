## 2. CornerResolver 冻结职责到底是什么

3-2.md §4.1原文：

> 当前帧定位步骤：依据结构对应找到相邻外边→原图局部区域提取轮廓边段→普通直线拟合→求交→检查交点在实际转折附近且误差合格。不接亚像素插件。M缺失、必要边不可分、交点病态则该假设无完整检测。

因此它应当做：消费已建立的结构对应，按P0～P3绑定选择当前原图真实邻边，拟合求交，给出可追溯证据与失败原因。边提取和拟合**本来就在职责内**，不是应当删掉的越权工作。

越界在于`find_component()`偷偷重新认定身份：缺assignment时，从所有白块中强选离模型锚点最近的一个。冻结允许模型投影引导搜索，但没有授权“距离最近＝M1”。

3-2.md §4.4原文：

> 四点都有当前允许证据；必要结构未被边界截断；点有限不重复、凸、不自交；拟合及交点误差合格；原图映射正确；没有无法消除的几何冲突。失败则empty，不裁坐标到画内，不用仿射或历史补点。

`find_component()`现状不是“直接把投影当P1”，应准确称为**未经验证的观测身份替代**。它可能拿到真实白块，但真实白块不等于正确白块，后续只拟合两条线仍不能证明M身份。

### 5.1 G3/G4：采用合成统计法，明确上限与下限

**认可合成统计法作为预算生成方法。** 需要修正的是：`min_edge_points`属于下限，不能用均值＋3σ作为最少点数；“P99远大于”没有可执行定义，改为上限始终取两者较大值。三倍标准差不是所有样本必过的数学保证，非正态误差尤其如此；这里它是工程校准方法，不宣称99.7%覆盖。依据：[NIST关于3σ及偏态分布的说明](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc31.htm)。

预算**方法**随本终稿确定；预算**实际数值**须生成测量报告后由用户批准。本文没有真实实验结果，不填任何生产预算数值。用户批准后再同步`detector.yaml`、强类型配置及`config.cpp`加载/校验/导出，禁止默认为已批准。

### 5.4 指标、统计单位与公式

对每个样例的四个角/八条边先求该样例最坏指标，再统计样例间分布，避免把同一图内相关的边当成独立样本并低估失败风险。保留每角每边原始值，不只留汇总。标准差用样本标准差（分母n−1）；分位数用nearest-rank：排序后取第ceil(p×n)项。n<2不产出预算。

| 字段 / 指标 | 单样例统计量 | 定值规则 |
|---|---|---|
| `max_corner_error` | 四角中，拟合交点到其**当前实测转折连接弧**的最短距离最大值，原图px | 上限U，向上到0.5px |
| `max_edge_direction_diff` | 八条拟合边与该候选hypothesis投影模型边的无向锐夹角最大值，度 | 上限U，向上到整数度；不能将角差截断在现有门限后再统计 |
| `max_support_extension` | 从交点向每条拟合支持段做有向投影；落在线段内为0，在线段外取到近端点的延伸距离；八条最大值，原图px | 上限U，向上到0.5px；不用“到两个端点距离最大值”，后者会把整条长边算成误差 |
| `max_line_fit_residual` | 每线支持点到拟合线的平均垂距，八条线中最大值，原图px；每线最大垂距另记诊断 | 上限U，向上到0.5px；与§7择优的两线残差和是不同指标 |
| `min_edge_points` | 每样例八条边中最少的**去重实际支持像素点数**，整数 | 下限L，向下取整数；并要求至少3个不同且有有限跨度的支持点，见下文 |
| 真值定位误差预算 | 四个输出物理角相对连续名义真值的欧氏误差最大值，原图px | 单独上限U，向上到0.5px；作为合成/人工真值验收指标，不能混叫`max_corner_error`或供运行算法读取真值 |

误差上限统一：`U_raw=max(μ+3s, P99)`；角度`ceil(U_raw)`，像素`0.5×ceil(U_raw/0.5)`。不再使用“远大于”这一模糊分支。先按L/M、工作图尺度、圆角/噪声组合分别汇报，再取各层上限的最大值作为本期单套参数；不通过混合平均稀释最难条件，不按旋转角设置视频拟合参数。

支持点下限统一：`L_raw=min(μ−3s, P01)`，各层分别计算，最终取最小层下界，向下取整数。生产阈值不低于3：两点总能确定直线且无法提供额外残差证据，至少第三个不同支持点是结构性要求，不是经验容差。若某个必测条件实际不足3点，记录算法/支持范围失败，不能靠取整为0或改成2点宣称通过。点数之外必须检查实际支持跨度与非退化，3个相邻像素不自动代表充分证据。

其他G4字段（边位置带、ROI扩展、圆角连接弧识别、assignment几何/面积容差、仿射退化及资源上限）**不能统统套上μ＋3s**：

- 有明确定义的非负观测误差上限，可采用上述U法并注明单位与测量对象。
- 点数/支持长度下限用下尾统计；病态角/矩阵退化须结合已批准模型范围和条件数，不由“正例角度平均值”猜门限。
- 候选/扩展/假设数量上限是资源策略，引用已批准资源预算并测边界，不能用正例候选均值＋3s取代有界搜索设计。
- 若某字段无法不依赖自身门限而测量，先报告测量/识别规则未闭合，补定义和合成证据，不暗填暂定参数。原来冻结未具体化的地方保持可见。

### 5.5 防止测分布变成调阈值

1. 校准runner允许报告原始测量而暂不应用“待求误差上限”，但仍检查真实边、正确物理身份、有限值、凸性等结构要求。生产路径不允许以该模式发布Detection。
2. 只有真值确认身份/边正确的定位结果进入有效误差统计；找错边、求不出角、崩溃和缺支持都计入独立失败分母，逐条记录。**任何结构失败未解决前不能批准仅成功样本统计出的预算**，不能删失败样例。
3. σ=1.0的噪声不意味着角点误差也服从高斯分布，不能直接用1.0当定位预算。噪声在大量黑白平坦区域可能被阈值完全滤掉，真实测得零方差也要如实报告，不人为添加“更合理”的方差。
4. C中的确定性无噪声结构测量必须全部成功。噪声样例的结构性错误必须修算法；允许统计尾部的保守拒绝按§9门槛评价，不能将3σ/P99说成100%覆盖。如果C有超界尾部，报告最大值及尾部数量，不额外抬到最大值来换全绿。
5. 得到候选预算并获用户批准后固定配置，再跑H；H失败先定位算法/fixture/条件问题，不放宽预算。修算法后重新生成C报告，用相同规则重算并再次提交数值审批；不得拿H错误自动反算门限。保留版本，明确H已被看过，不再宣称完全未接触的测试集。
6. 视频只在数值固定后回归。帧1200及其他视频失败不能用于重算μ/s或改变分位数。

### 6.1 M/S assignment补丁：本轮直接完成

| 步骤 | 固定行为 | 防止的问题 |
|---|---|---|
| C1 输入核对 | 拒绝缺失/重复L0/L2/L3引用、同片多身份、非有限/退化/镜像affine、CLEARLY_INCOMPLETE父假设；不改父假设的三L坐标、affine或评分 | 不让非法父假设借补片转正；有效旧三L假设保持原值 |
| C2 候选来源 | 用真实WhiteComponent集合，排除三L已用ID；不依赖旧supported_classes中“M/S”标签，因为现有分类不可靠。建立component_id查找表，不把ID当数组下标 | 原分类未改，但不会把M因标签列L而漏掉 |
| C3 逐片验证 | 对模型M1/S1a/S1b分别投影完整多边形，仅作搜索/结构核验；比较真实轮廓与模型投影的双向有限边界距离、循环边对应、凸凹拓扑与相对面积。M必须是对应凹结构，S必须有方块模型在仿射下的四边结构；不要求图像直角 | 不能凭最近中心、一个面积值或单向平均残差确定身份 |
| C4 相对面积 | A_ref为父假设三L真实观测面积中位数；观测候选面积/A_ref与已确认模型面积比比较，容差来自批准预算。M160只在模型确认后参与；不复用旧0.5～2等占位值 | 不动旧三L验证，同时补全步骤符合冻结相对尺度依据 |
| C5 有界组合 | 按固定模型顺序M1、S1a、S1b做深度优先枚举；每一步检查component未占用及空间/拓扑一致性；每次候选扩展计数，达到批准上限且尚有未搜分支则标resource_truncated | 禁止无界三重组合，也不选最近者当唯一 |
| C6 多解保留 | 每个合格一对一组合复制父假设并追加三条assignment和验证证据；保留所有已验证分支。按父ID＋三片component_id稳定排序/去重，不按分数只留一个 | 不抹去方向竞争解释；CornerResolver消费确定分支而不重认身份 |
| C7 无完整组合 | 父假设未通过补全，不送入完整decode；记录缺M、缺S、结构冲突或预算不足。真实必要物理角缺失则empty，不能补点 | 拒绝有原因、无模型预测检测 |
| C8 未解与截断 | 沿用已有resource_truncated并合并补全截断；明确记录搜索穷尽与未穷尽。没有证据不能写“已唯一”；截断未排除几何冲突时按现有保守策略empty | 剩余一个输出分支不等于搜索空间只有一个解释 |

**S缺失的边界：**本补丁按冻结Block2的完整分段结构验证路线输出完整M/S对应，不新增“忽略S仍正常解码”降级路径。S不可辨但M和三个L物理角可见的情况，记录`SEGMENTED_SUPPORT_INSUFFICIENT`，不得称“已证实物理角缺失”。若该情况影响已约定召回目标，应提交证据评审是否允许部分语义支持；不能临场把“方向unknown”当作绕过结构验证的万能许可。

必要的点到有限线段距离、轮廓双向距离等helper只放新模块或真正共用的内部文件；不修改旧三L算法的调用路径。完整轮廓按其分段线性边界计算距离，可按批准采样步长验证；不以CHAIN_APPROX_SIMPLE点数冒充边界证据量。

| 新增预算字段族（仅名称/单位，本版不填值） | 适用范围 |

## 7. resolveObservedCorners 具体修复逻辑

以下为实现伪代码，不是新增公共API；G1/G5已批准，可立即实施对应框架。G3/G4预算相关逻辑可以编码并用显式测试配置验证，但正式数值待用户批准。内部helper按§6.2拆分，中文注释说明旧问题及修改原因。

### 7.1 先把输入不可信与图像未检测区分清楚

```text
result := FAILED, measurement := empty
检查original_image非空、BGR8、尺寸合法；scale有限且>0
检查affine是有限的2×3 double矩阵、可逆且非镜像
检查model绑定存在、顶点/邻边索引合法、确为指定凸角
若hypothesis.completeness == CLEARLY_INCOMPLETE：拒绝
逐物理角按model_part_id查唯一assignment和真实component_id
缺失/重复/引用不存在/同一component承担不同物理片：拒绝
特别：没有M1 assignment即MISSING_M_ASSIGNMENT，不搜索“最近M”
```

不得用仿射预测角作为measurement默认值。所有输出只在四角均有合格证据之后一次性填入成功结果。

### 7.2 原图取证，不把稀疏工作图点伪装成原图支持点

1. 保留工作图component仅作身份、位置和候选范围依据；用已知缩放映射将其范围和模型边搜索带映到原图，保留工作图与原图坐标域标签。
2. 在原图候选区域按批准且记录的白阈值提取轮廓，使用`CHAIN_APPROX_NONE`保留真实连续像素点。ROI人工边界与原始画面边界分别标记；ROI边生成的闭合段不得参与边拟合。
3. ROI按投影片段尺寸与批准margin比例确定，不再有`max(10,50*ratio)`。ROI只是优化；若所需边碰ROI人工边界，扩大到该片完整支持区域重新提取一次；仍不足即拒绝，不把截断闭合线当真实边。
4. 原图轮廓与已assigned工作图片段按映射重叠和完整模型轮廓一致性验证。多个不能排除的原图轮廓，不用最近或首个强选：返回`AMBIGUOUS_COMPONENT_SUPPORT`。此时可能丢召回，须记录，不能从失败竞争解释推断方向唯一。
5. 每个轮廓保存有序点及稳定编号；允许在完整轮廓上做一次批准epsilon的简化以标记转折。不能先筛点丢连通性，再`closed=true`造新边。

像素中心映射和坐标边界按preprocess实际约定统一；使用cv::resize的采样中心关系时，点的逆映射为`(x_work+0.5)/scale_x−0.5`，y同理。它只用于搜索定位；最终四点直接来自原图拟合，无需再除scale。必须用多尺度合成验证该约定，不把“整数轮廓坐标就是连续物理边界”当事实。

### 7.3 联合匹配两条指定外边，而非各找一个方向最接近的边

```text
从完整原图轮廓建立连续边弧（保留原始点索引）
枚举与binding两条模型边分别相符的相邻弧对
    模型变换后的边只给方向/位置搜索带
    对每弧检查：位置带、无向方向差、点数、有限跨度
    检查两弧属于同一已assigned片、对应指定外边、之间为凸转折连接弧
    不准选择同一支持弧两次，不准用内侧平行边替代外边
    按批准规则剔除转折连接弧，仅拟合两侧直线支持点
    普通fitLine -> 每线原图残差、支持跨度
    theta = acos(clamp(abs(dot(unit_a,unit_b)),0,1))
    theta低于批准下限 -> 拒绝（同时覆盖0°与180°方向表示）
    求交点；finite检查
    交点必须贴近当前实测转折连接弧
    两有限支持段延伸到交点的距离必须在批准预算内
    残差/交点误差/截断均通过 -> 保存一个观测解
没有解 -> FAILED
若多个解的四点几何不能在批准预算内一致 -> FAILED/歧义原因
若一致 -> 保留拟合残差最小的实际测量，稳定证据ID破平局
```

这里新增的方向/位置带、连接弧剔除、有限段延伸预算必须由G4填入并确认。**文档没有这些数值，本稿也不捏造。** Codex可实现参数字段与合成测试，不得把暂定值当正式验收通过依据。

### 7.4 证据字段和原始误差

每角至少保留：physical_corner、component_id、model顶点/边ID、两条连续支持弧的原图点和编号、拟合线、有限段端点、intersection、每线平均垂距/最大垂距、交点到实测连接弧距离、真实边界截断标志。

用于多假设择优的`error_`明确定义为两线原图平均垂距之和；交点误差另存，不能继续把两者混为一个max。该定义属于G3批准内容，禁止保留旧值的误导注释。最终Validator复查证据与四点一致、ID有效、误差有限及预算合格。

原始定位误差分两种：拟合残差始终可量测；四点对真值的定位误差仅在合成或有人工真值时计算。没有真值的实拍帧写null及原因，不把拟合残差叫“定位误差真值”。

## 8. 集成、语义和排序的精确修复

```text
decodeStage:
  输入必须是completeSegmentedAssignments输出的批次
  对每个非CLEARLY_INCOMPLETE假设:
    resolveObservedCorners
    失败记录stage/corner/reason，不静默continue
    成功先orderScreenCorners，再validateDetectionGeometry(original_size)
    仅完整合法measurement进入resolveSemantics
  有未排除的候选但因取证歧义/资源不足无法解析:
    记录搜索不完整；不可据剩余唯一项宣称方向唯一
    若未解析项可能对应不同几何且无法排除 -> empty
  resolveSemantics -> 几何冲突empty
  选择实际已有measurement；不平均
  最终Detection.corners取对应ScreenOrder.screen_points
  orientation = mapping仅当orientation_unique，否则nullopt
  marker_code = nullopt; confidence无定义则nullopt
  bbox = 原图四点的min/max构造Rect2f，不用整数boundingRect引入额外像素
```

- `resolveSemantics`几何比较保留循环对应；所有measurement必须预先合法。平局按四角稳定证据ID字典序，不按vector进入顺序。集合相等门限采用明确的≤关系，则配置0表示精确相等；浮点数值测试另有机器精度容差，不把0改成隐含正门限。
- `orderScreenCorners`先验证finite，再生成携带物理索引的顺时针四个循环候选；先求`E_min`，再收集满足冻结64ε公式的所有候选；若数量>1置tie并从该集合取(y,x)字典序最小者。这样不会因后来的略小能量漏记平局。
- `validateDetectionGeometry`除了点有限/凸/边界，还检查screen_points与mapping重建结果一致、四角证据完整、intersection与physical_corner一致、所有误差合格、确证截断必拒。`reject_truncated_corner=false`不能成为对外发布缺角Detection的开关。
- 公共`Detector::process`值初始化结果、填帧号/时间、恢复格式/序列/时间来源检查；当前稳定阶段未就绪仍`NOT_READY`，不得产生透传track。decode结果只由阶段audit独立验收。本轮不实现任何稳定算法。
