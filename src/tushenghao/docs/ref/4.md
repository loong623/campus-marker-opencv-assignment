## 2. 初始提案

### 2.1 职责划分

保留当前目标关联及基础四点平滑；历史语义显示与有效检测分开。当前Detection为空时有效Detection和TrackResult都为空，可短期保存内部选择参考，但不能继续绘制历史有效框或四点。

稳定层采用集合接口，本期最多单track，不实现卡尔曼、预测、多目标匹配和持久身份保证。

### 2.2 对应先于平滑

屏幕排序跨菱形分界可能循环换位，不得直接平滑相邻帧corners同下标。方向均可信时用物理对应；否则枚举保持环绕关系的循环对应。歧义时使用当前原始测量并重置，不以历史方向替当前消歧。

平滑后检查几何有效性、重新进行屏幕排序并更新可信方向映射。失败回退当前原始测量，不将可信当前检测删掉。

## 4. 完整冻结实现计划

### 4.1 平滑公式

定义当前测量z_t、上次稳定位置p_(t-1)，时间差Δt单位秒：

\[
p_t=\alpha(\Delta t)z_t+[1-\alpha(\Delta t)]p_{t-1}
\]

由Δt0=0.014s、α0=0.7：

\[
\tau=-\frac{0.014}{\ln(0.3)}\approx0.011628s,
\qquad\alpha(\Delta t)=1-\exp(-\Delta t/\tau)
\]

数值实现使用：

```cpp
alpha = -std::expm1(-dt_seconds / tau_seconds);
```

| 间隔 | 当前测量权重 |
|---|---|
| 7ms | 1-sqrt(0.3)，约0.452277 |
| 14ms | 0.7 |
| 28ms | 0.91 |

配置只存reference_dt_ms=14、reference_alpha=0.7，构造时算tau，避免三个值互相矛盾。

无平滑历史、失检恢复、关联失败、对应不可信、历史超期、Δt=0或平滑结果非法时不使用公式，采用当前原始测量。时间倒退清状态并INVALID_INPUT。

### 4.5 关联与对应规则

无历史选最大图像面积候选；面积相同且双方质量有定义且可比才比较质量，否则稳定候选顺序。有历史用v0.8位置/尺度门限；多个可能关联且无法区分则重选并重置平滑。无当前候选输出空track，平滑历史失效。关联失败不能删除已经可信的当前检测。

两帧方向可信时按物理编号对应；否则枚举四种保环绕循环对应，比较归一化位移。误差预算内无法区分则重置，不能另从视频拟合分差门限。历史方向不回填当前unknown。既有误差预算不足以确定唯一性时提交问题确认。

### 4.6 恢复与输出

失检恢复：未过期选择参考可辅助候选选择；本帧四点无论关联成功与否均从原始测量开始，下一连续有效帧才平滑。

- FrameResult.detections保存当前原始测量。
- TrackResult保存关联到其中某项的稳定结果。
- 平滑后按板块3重新排序，同步更新当前可信方向映射；当前未知则保持未知。
- bbox由稳定四点重算，不独立平滑。
- 当前empty时detections/tracks均空。
- 平滑非凸、自交、越界或偏离当前测量超预算时，回退原始测量并重建历史，不误报失检。
- 换源/循环/reset清状态；时间或帧号非法按已有INVALID_INPUT契约处理。

### 4.10 必测序列及完成标准

- 有效→有效：对应正确，按实际时间权重。
- 有效→empty：立即无有效四点/track。
- 有效→empty→有效：恢复不混旧点。
- 方向已知→未知：当前和稳定方向不回填。
- 屏幕分界跨越：物理对应正确，无角点拉扯。
- 关联失败且当前有效：输出当前原始结果。
- 平滑非法：回退并重建历史。
- 时间倒退/换源/循环/reset：正确清理。
- 双实例交错与分别运行一致。
- 合成值后缺失：第1～5保留、第6清空，不改变有效输出。

审计记录含帧号、时间差、权重、关联/重置原因、原始/稳定四点、显示桥接状态；这是行为验收，不等于板块5计时已完成。所有阶段实际就绪后，公共process才由NOT_READY进入正常DETECTED/NOT_DETECTED。
