## 2. 初始提案

### 2.1 文件职责与边界

原始核心入口为detector.hpp/cpp及config/detector.yaml；main负责输入、调用和显示，Detector不打开视频、不调用waitKey、不保存视频。

固定类型attributes承载方向和编码，避免任意键值字典。当前Detection、历史显示、输入错误、算法未就绪必须分别表达。

### 2.2 Detection与FrameResult

Detection只表示当前可信测量：MARK类别、四点、由四点推导的bbox、attributes、可选置信度和质量标记。置信度无定义时为空，不填1；几何可信但ID不明时可保留Detection，语义字段unknown。四点不可信则无Detection。

FrameResult包含帧号、时间、当前detections、tracks、独立display_state及diagnostics。历史显示必须带来源帧和年龄，不携带供下游使用的有效四点。

### 2.3 四阶段

| 阶段 | 职责 |
|---|---|
| preprocess | 工作图与显式坐标映射 |
| detect | 候选、白片证据、完整性状态 |
| decode | 四点、最终有效性、方向/编码 |
| stabilize | 当前测量关联与稳定；历史显示独立 |

Candidate为结构化输入，不把“恰好3L+1M+2S”写成对象构造前提。内部中间字段可随后续几何设计完善，公共有效性契约不变。

### 2.4 生命周期与升级接口

配置启动时加载和校验，不实现热加载；实例独立、可reset，无全局/static历史状态。输入格式错误不是未检测到；换源、循环、时间倒退需处理重置。PnP只预留消费可信四点、物理对应、相机和目标模型的边界；多目标使用集合接口，本期单track，不实现多目标关联或动态插件加载。

### 2.5 参数迁移原则

960×720、threshold=200、MAX_HOLD=5可作为来源明确的旧版起点，不是泛化结论。旧绝对面积分类700/250/80、nearest-L margin和屏幕排序语义不进入新算法配置。相对面积与几何容差等待图纸及误差模型，不填假值。

## 5. 完整冻结实现计划

### 5.1 文件清单

全部位于src/tushenghao/：

```text
CMakeLists.txt
README.md
detector.hpp
detector.cpp
detector_types.hpp
detector_config.hpp
detector_config.cpp
main.cpp
config/detector.yaml
tests/config_contract_test.cpp
tests/detector_contract_test.cpp
docs/block1_acceptance.md
```

types负责公共数据；config负责强类型加载、校验和实际配置导出；detector负责生命周期和阶段骨架；main提供无界面配置/骨架验证。使用普通C++测试程序及CTest，不新增测试框架依赖；失败返回非零，不依赖Release可能关闭的assert。

### 5.2 公共类型

采用C++17和mark命名空间。

| 类型 | 字段及契约 |
|---|---|
| FrameInput | cv::Mat image、uint64_t frame_id、int64_t timestamp_us、TimestampSource time_source |
| Detection | MARK类别、array<Point2f,4> corners、Rect2f bbox、Attributes、可选confidence、quality_flags |
| Attributes | 可选orientation和可选MarkerCode |
| orientation | 可选“物理角部→输出四点索引”对应关系；物理定义及判定留板块3，本板块为空 |
| MarkerCode | scheme及非负value；scheme本期固定为空字符串，表示未编码；不得将value解释为有效编码，未编码通常以可选值为空表达 |
| TrackResult | 当前测量在detections中的索引和稳定结果；最多一个 |
| DisplayState | 历史语义显示值、来源帧、年龄、是否沿用历史；没有四点 |
| FrameResult | 帧号、时间、状态、detections、tracks、可选display_state、diagnostics |

状态：NOT_READY=算法未实现；INVALID_INPUT=输入非法；NOT_DETECTED=算法已就绪但无可信目标；DETECTED=有当前可信目标。骨架合法调用返回NOT_READY。

### 5.3 配置签名

```cpp
AppConfig loadConfig(const std::filesystem::path& path);
void validateConfig(const AppConfig& config);
void writeEffectiveConfig(const AppConfig& config,
                          const std::filesystem::path& path);
```

加载/校验失败统一ConfigError，含文件与字段路径。公共头不暴露FileNode。AppConfig区分应用层和DetectorConfig；Detector不接收窗口/视频路径。构造Detector时再次校验直接传入的配置。

### 5.4 Detector签名

```cpp
class Detector {
public:
    explicit Detector(DetectorConfig config);
    ~Detector();
    Detector(const Detector&) = delete;
    Detector& operator=(const Detector&) = delete;
    FrameResult process(const FrameInput& frame);
    void reset(ResetReason reason) noexcept;
    const DetectorConfig& config() const noexcept;
private:
    struct Impl;
    std::unique_ptr<Impl> impl_;
};
```

- 单实例顺序调用，不承诺线程安全；多实例隔离。
- 图像在调用期间有效且只读，不跨调用保留像素引用。
- 帧号递增、时间不得倒退；不从帧号猜测间隔。
- 换源/循环由调用者先reset；检测到时间倒退、帧号不递增、时间来源改变，清状态、返回INVALID_INPUT、不继续检测。
- 不实现热加载。

内部声明：

```cpp
PreparedFrame preprocess(const FrameInput& frame);
CandidateBatch detect(const PreparedFrame& frame);
DecodeResult decode(const PreparedFrame& frame,
                    const CandidateBatch& candidates);
StabilizeResult stabilize(const std::vector<Detection>& detections,
                          const FrameStamp& stamp);
```

每阶段带状态，未实现即停止，不把空集合伪装成完成算法。PreparedFrame带映射和帧上下文，CandidateBatch带白片/候选，DecodeResult带当前检测及拒绝原因，StabilizeResult带track与独立显示。板块1不实现分割、分类、四点恢复、解码或平滑。

### 5.5 YAML冻结字段

OpenCV YAML头为%YAML:1.0，开关使用整数0/1。

| 字段 | 初值 | 校验 |
|---|---|---|
| schema_version | 1 | 仅支持当前版本 |
| input.pixel_format | BGR8 | 本期唯一格式 |
| input.timestamp_unit | us | 微秒 |
| preprocess.work_width | 960 | 正整数 |
| preprocess.work_height | 720 | 正整数，禁止静默拉伸比例 |
| preprocess.threshold | 200 | 整数0～255，旧版起点 |
| detector.mode | skeleton | 本板块只允许骨架 |
| temporal.stabilization_enabled | 0 | 设1报未实现 |
| temporal.display_hold_enabled | 0 | 设1报未实现 |
| temporal.max_hold_frames | 5 | 非负整数，仅历史显示参数 |
| output.show_window | 0 | 本板块设1报未实现 |
| output.show_held_state | 0 | 本板块不可启用 |
| debug.timing_enabled | 0 | 板块5前不可启用真实阶段计时 |
| debug.draw_candidates | 0 | 本板块不可启用 |

全部字段必填；缺失、类型错误、未知/重复字段、非法范围、非有限数、未知版本必须报错；不支持合并键/锚点等扩展。导出后再加载值一致。解析器不能可靠实现校验时报告阻塞，不擅自取消要求。后续板块新增参数须版本化，不在此填入几何占位数。

### 5.7 命令

仓库根目录执行：

```bash

cmake --build build/tushenghao --parallel
ctest --test-dir build/tushenghao --output-on-failure
```

check-config只检查配置；smoke-test使用固定合成彩色图，确认NOT_READY且输出为空，验证成功退出0，不表示识别成功。无需视频/相机/桌面。验收记录包含命令、退出状态、版本和摘要。
