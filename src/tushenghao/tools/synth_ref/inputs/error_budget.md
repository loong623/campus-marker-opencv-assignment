## 1. 误差项：定义、允许值和依据

| 项目 | 如何定义 / 允许值 | 依据与如何定值 | 当前状态 / 失败处理 |
|---|---|---|---|
| 理想模型位置关系 | 无噪声合成应满足模型仿射关系；仅允许与数值精度、条件数相符的浮点误差 | 已确认顶点经同一仿射变换；不能以观测容差掩盖坐标或对应错误 | 浮点测试容差待测试实现明确；失败先查坐标、编号、变换方向 |
| 边界观测误差 δ | 原始观测边到已知合成真值边的最大距离；允许值待测，单位px | 固定栅格化、像素相位、分割边界扰动；不能仅凭像素取整就声称总误差≤0.5px | 未测；圆角/模糊等超出模型的误差须单列 |
| 多边形简化 ε | 简化轮廓相对原始轮廓的距离预算；数值待测 | 同一组固定样本检查顶点/凹转折保留；不得反复调 ε 以凑六顶点 | 与δ分开记录；结构不可辨则拒绝 |
| 锚点误差 η | 凹转折观测与真值的距离；数值待测 | 边交点误差受夹角放大，不能直接设η＝δ＋ε；按合成真值测量 | 锚点近退化时拒绝，而非放宽 |
| 独立验证位置误差 | r_i＝观测点−仿射预测点；允许上限应覆盖观测误差＋拟合传播误差，数值待测 | 若三锚点各误差≤η，独立点模型重心系数为λ_j，则预测误差≤ηΣ\|λ_j\|；再加该验证点误差η_i，即 \|r_i\|≤η_i＋ηΣ\|λ_j\| | 条件性上界，不是已测参数；仅用于未参加拟合的点，不能用三拟合点自证 |
| 边方向 / 角度误差 | 比较观测边方向与**仿射投影后的模型边方向**，不检查原图必为90°；数值待测 | 若一段真值长度ℓ、两端误差各≤η，且2η<ℓ，则其方向偏差可界为asin(2η/ℓ)；预测边还须加拟合传播的方向误差 | 2η≥ℓ时方向无可用保证；短边或不稳定交角可拒绝，不能套固定大角度 |
| 面积测量误差 ΔA_i | 各白片相对合成真值面积的绝对偏差上界，单位px²；数值待测 | 必须用实际 contourArea 流程；同面积但不同周长/笔画宽的形状误差不同 | 不以像素计数替代轮廓面积后混用预算 |
| 面积比容差 | A_ref＝三个可信L面积中位数；对名义比r₀，允许区间由下行公式计算，不先填±百分比 | 共同比例的面积变化在共同仿射下抵消；分割误差不会抵消。M的r₀仅在坐标确认后启用 | ΔA与最小可分辨尺度未测，故区间待定 |
| 面积比区间公式 | 设真实L面积A、其参考测量误差≤ΔL，待验证白片误差≤Δi，A>ΔL，则比值范围为[max(0,(r₀A−Δi)/(A＋ΔL)), (r₀A＋Δi)/(A−ΔL)] | 分子分母取最坏误差的直接代数界；工程使用时还需从观测参考面积界定A，不把未知真值直接放入运行代码 | 合成试验可用真值A验证；运行时保守换算需列入参数确认结果 |
| 最小可分辨笔画 / 间隙 | 工作图中笔画与间隙宽度下限，数值待测 | 图纸含8宽笔画、M的6宽缺口等；尺度缩小后可能消失/粘连，必须合成测出支持边界 | 这是分辨率限制，不是旧绝对面积分类；条件外可拒绝 |
| 仿射适用范围 | 最小尺度、最大各向异性（奇异值比）、允许条件数，均待合成验证确认 | 仅承诺批准范围的旋转/缩放＋仿射近似；不能把欧氏直角当仿射不变量 | 范围未确认不宣称全仿射鲁棒 |
| 退化与镜像 | 奇异/近共线拒绝；不允许模型到观测发生镜像；近退化数值界待定 | 三锚点拟合可解性与数值稳定性；整体变换行列式符号，不能混淆局部模板绕向 | 锚点不稳定即拒绝；不增大误差换取通过 |
| 制造 / 圆角误差 | 无已知允许值 | 图纸无公差和圆角半径资料；不能伪装为采样误差 | 本期理想模型限制明确记录；需要支持时补证据并用户确认 |

## 2. 固定合成实验：生成依据后再填配置

以下是**建议的实验取样网格**，不等于这些条件全部保证检出；用户确认后锁定版本。没有使用当前视频选值。

| 实验项 | 建议固定输入 | 选择依据 | 应输出的证据 |
|---|---|---|---|
| 理想几何 | 已确认模型；0～345°每15°；各向异性比1、1.5、2；分别组合变换并保留真值 | 整圈方向和逐级形变的覆盖试验，数值为试验设计而非图纸事实 | 真对应在集合中；非法镜像、共线、错对应的拒绝结果 |
| 图像尺度 | 以变换后的最窄笔画宽为轴，取2、3、4、6、8、12px | 从明显欠采样向可分辨区间探测；不根据测试视频尺寸选点 | 每一尺度的结构保留、锚点/边/面积误差；失败尺度不默默删掉 |
| 像素相位 | x/y方向分别偏移0、0.25、0.5、0.75px，笛卡尔组合 | 覆盖栅格对齐敏感性，四分之一像素是实验步长 | 最坏误差及对应样例ID |
| 边界扰动 | 固定0、±0.5、±1px法向偏移；独立记录收缩/膨胀与局部扰动 | 人为压力阶梯，用于界定支持条件；不声称真实成像误差恰为1px | 无粘连与粘连分别记录；拓扑破坏不能靠面积容差补救 |
| 栅格化与分割 | 固定生成器版本、填充规则、抗锯齿策略、阈值及随机种子；全程保存 | 同样模型用不同填充方法可产生不同轮廓面积 | fixture说明、输入图、真值、配置和测量CSV/表格 |
| 负例 | 四侧裁切、缺片、普通白块、粘连、错误组合、对称多解、资源上限前后 | 来自冻结验收要求 | 拒绝原因正确；多解不强选；截断可见 |
| 超出范围 | 更窄笔画、更强仿射形变、一般透视 | 检查失效行为；不是增加成功承诺 | 失败记录；不能保证所有模型外输入都被完美识别并拒绝 |
| 参数确认产物 | 支持范围＋每项误差上界＋最坏样本＋拒绝例＋资源计数 | 合成样本最大值只证明已测网格，不证明连续全空间 | 用户确认后才写入配置；视频只作回归，不反向放宽参数 |

## 3. 资源预算（待批准工程提议）

数量上限用于界定计算与存储成本，不是目标几何事实，也尚无14ms性能保证。只达到计数上限且仍有未处理工作时才标记截断；刚好全部处理完不误报。

| 资源 | 建议上限 | 依据 / 成本 | 达到上限时的行为 |
|---|---|---|---|
| 进入形状分析的白片 | 128个/帧 | 人为有界工作集；单目标名义6片之外留杂波空间，不来自视频计数 | 尚有未处理白片时标RESOURCE_LIMIT；记录总数/处理数，不静默当完整搜索 |
| 可进入组合的L候选 | 16个/帧 | 至多C(16,3)＝560组三元组；不会随背景片数无界增长 | 超过16时截断标记；不能声称截断后留下的唯一假设就是唯一解 |
| 三元组 | 最多560组/帧 | 从16个L候选组合得到的精确上界；先做局部兼容筛选再拟合 | 不做全白片四元组合；兼容检查依据批准模型和误差范围 |
| 仿射对应拟合 | 最多3360次/帧 | 每组三元组3!＝6种对应，560×6 | 退化/镜像可提前拒绝单个对应；不可在找到第一个合格对应后停止并称唯一 |
| 分段片对应扩展 | 最多10000次/帧 | 新增显式计数以防M/S对应组合成为隐藏爆炸；10000是待实测的工程提议 | 每扩展一个部分对应计1次；上限处停止扩展、保留已验证结果并标截断 |
| 保存几何假设 | 最多64个/帧 | 限制下游与存储；不是场景最多64个解的承诺 | 更多合格假设存在时标截断；不得以最高分偷换全部通过集合 |
| 原始轮廓提取 | 不声称上述128能限制findContours自身成本 | 上限发生在形状分析前；全图扫描与原始轮廓分配仍依赖图像/杂波 | 合成杂波压力测试测量；若不满足资源要求，停下评审，不虚报有界全流程时间 |
| 墙钟超时 | 本阶段不新增检测阶段毫秒截断值 | 用户系统总处理目标约14ms，尚无此硬件模块分解和实测依据 | 记录耗时；不把14ms直接当detect限时，不擅自削减范围 |

## 4. 早期停止与拒绝规则

| 条件 | 处理范围 | 动作与理由 | 不能做的事 |
|---|---|---|---|
| 模型缺尺寸/未批准 | 模型加载 / 依赖工作 | 阻塞依赖模型的实现与验收；可继续独立框架 | 从baseline面积或截图像素编尺寸 |
| 白片结构不可信 | 单白片 | 保留未分类或拒绝类别假设；记录原因 | 为凑L六顶点重复调简化参数 |
| 三L不足/不兼容 | 当前组合 | 不进入仿射拟合；继续其他合法组合 | 用中心亮点或历史点补L锚点 |
| 退化、镜像、独立残差超界 | 单对应 | 拒绝该对应，继续其他对应 | 放宽阈值到当前视频通过 |
| 观察到边界确实切断必要结构 | 当前目标候选 | 早期判不完整，不进入完整解码 | 把“bbox碰边”单独当必然出画，或把“未碰边”当完整证明 |
| 完整性暂不确定 | 当前目标候选 | 保留待验证状态，交板块3最终检查 | 用三个角部可见代替四点有效性 |
| 任一资源上限耗尽且仍有工作 | 当前帧搜索 | RESOURCE_LIMIT＋已验证假设＋具体计数；搜索不完整传给下游 | 默认为无目标、隐瞒截断、据此确认唯一方向 |
