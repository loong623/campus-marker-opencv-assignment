| 边与身份注意事项 | 规则 |
|---|---|
| 全局边编号 | 每个白片的 e 编号沿用局部 v 编号；例如 L0.e2＝(30,8)→(8,8)，M1.e3＝(72,14)→(72,8) |
| 模板绕向 | L3 的模板变换改变多边形绕向。凹凸判断必须使用有向面积归一化；模板内部变换不能误当作观测仿射允许镜像 |
| 三个拟合锚点 | L0(8,8)、L2(72,72)、L3(8,72)；不能把这三点的拟合零残差当独立证据 |
| 独立证据 | 未用于拟合的 L 顶点/边、M1 与两个 S 的对应；身份来自整体结构，不来自最近 L 或屏幕 top/left/right |
| P0～P3 的用途 | 表示图纸物理标签；板块2不据此生成最终屏幕四点。投影预测不是当前可见角点测量 |
| 可变换关系 | 共线、平行、同一仿射下的面积比可保留；原图直角和欧氏长度比在一般仿射下不保留 |

## 4. 面积与比例：全部保留推导链

| 项目 | 名义值 | 来源与算式 | 启用前提 |
|---|---|---|---|
| A_L | 416 u² | D2～D4：30²−22²＝416；亦为两条30×8矩形减8×8重叠 | 用户确认理想直边模型 |
| A_S | 64 u² | D9：8×8 | 两个 S 的尺寸解释确认 |
| A_M | **160 u²，仅条件推导，不自动采用** | D8：14²−(14−8)²＝196−36；亦为14×8＋14×8−8×8 | 用户明确确认 D7/D8 与 M 顶点表；不是图纸直接标注面积，不是视频实测 |
| S/L | 2/13≈0.153846 | 64/416 | 上述尺寸成立、共同仿射；观测容差另定 |
| M/L | 5/13≈0.384615，仅条件值 | 160/416 | **M 模型确认前禁用**；不因旧视频面积接近而启用 |
| 实际轮廓面积 | 未知 | 圆角、采样与分割会改变 OpenCV 轮廓面积 | 不把名义面积直接当像素面积阈值 |

## 5. 用户核对关卡

| 核对项 | 需要确认的内容 | 未确认时处理 |
|---|---|---|
| 80 的含义 | 是否确为白结构外角跨度，而非壳体尺寸 | 阻塞全局模型配置；可做独立加载/校验框架 |
| A 详图尺寸基准 | 横向从右沿、纵向从上沿量取，8/14/22/30是否如 D7 | 阻塞 M/S 配置，提交图纸疑点，不从视频补值 |
| M 面积 | 上述顶点是否正确，是否批准“名义160、观测另预算” | 不写死160，不启用5/13门限 |
| 单位与制造细节 | 是否有原始图纸单位、圆角或公差补充 | 暂用 u；不支持由本表直接宣称真实尺寸/PnP标定完成 |
| 通过后的动作 | 用户确认坐标表 → 模型加载与多边形面积测试 → 固定合成实验 → 误差预算确认 | 坐标表通过不等于误差预算通过 |
